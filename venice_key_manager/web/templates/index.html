🔌 Model Context Protocol (MCP) Integration

Connect Cursor, Claude Desktop, Antigravity, or Hermes Agent to this Venice Key Manager MCP server.

Configuration for Claude Desktop & Cursor

Add the following block to your claude_desktop_config.json or Cursor MCP settings:

claude_desktop_config.json 
{
  "mcpServers": {
    "venice-key-manager": {
      "command": "python",
      "args": ["-m", "venice_key_manager.mcp_server"],
      "env": {
        "VENICE_API_KEY": "YOUR_VENICE_ADMIN_KEY"
      }
    }
  }
}
