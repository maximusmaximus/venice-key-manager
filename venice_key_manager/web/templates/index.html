🔌 Model Context Protocol (MCP) Integration

Connect Cursor, Claude Desktop, Antigravity, or Hermes Agent to this Venice Key Manager MCP server.

Configuration for Claude Desktop & Cursor

Add the following block to your claude_desktop_config.json or Cursor MCP settings:

claude_desktop_config.json 
{
  "mcpServers": {
    "venice-key-manager": {
      "command": "python",
      "args": ["-m", "venice_key_manager.mcp_server"],
      "env": {
        "VENICE_API_KEY": "YOUR_VENICE_ADMIN_KEY"
      }
    }
  }
}

Available MCP Tools Registered

venice_list_keys - List keys with spend & limits
venice_create_key - Mint key with budget cap
venice_cycle_key - Rotate/replace an existing key
venice_update_key_limit - Adjust budget or period
venice_revoke_key - Delete key permanently
venice_get_account_balance - Check USD/DIEM & alerts
venice_list_models - Query models with E2EE filter
venice_test_inference - Quick health benchmark
venice_export_backup - Full state JSON backup
